# 🛒 Merchant Product App

## 📌 Introduction
The **Merchant Product App** is a Java-based application developed using Eclipse IDE. It is designed to manage products for a merchant by performing basic operations like adding, viewing, updating, and deleting product records.

---

## 📖 Description
This project demonstrates core Java concepts and follows a simple structured approach for managing product data. It can be used as a beginner-friendly project to understand CRUD operations and project organization.

---

## 🚀 Features
- ➕ Add new products  
- 📋 View all products  
- ✏️ Update product details  
- ❌ Delete products  
- 🧩 Clean and modular code structure  

---

## 🛠️ Tech Stack
- Java  
- Eclipse IDE  
- (Optional) JDBC / Hibernate  
- (Optional) MySQL / PostgreSQL
